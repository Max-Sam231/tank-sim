# HTML-структура документа

**Файл:** `index.html`

## Архитектура разметки

Главный файл разметки содержит все экраны и диалоговые окна симулятора. Переключение между экранами происходит за счет скрытия (`.hidden`) и отображения контейнеров `<section class="game-scene">`.

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Driver Sim</title>
  <link rel="stylesheet" href="./styles.css" />
  <script type="module" src="./main.js"></script>
</head>
<body>
  <main class="app">
    <!-- Глобальный пользовательский интерфейс -->
    <div class="ui-layer-global">...</div>

    <!-- Контейнер стартового меню -->
    <div class="start-menu-container" id="startMenuContainer"></div>

    <!-- Сцена: Ангар (виды: сверху, боковые) -->
    <section id="scene-hangar" class="game-scene hidden">...</section>

    <!-- Сцена: Обогреватель (обслуживание котла) -->
    <section id="scene-heater" class="game-scene hidden">...</section>

    <!-- Сцена: Ящик ЗИП (инструменты) -->
    <section id="scene-zip-box" class="game-scene hidden">...</section>

    <!-- Сцена: Кабина водителя (приборы и органы управления) -->
    <section id="scene-driver" class="game-scene hidden">...</section>

    <!-- Сцена: Кабина командира (вид из башни) -->
    <section id="scene-commander" class="game-scene hidden">...</section>
  </main>
</body>
</html>
```

## Детализация разделов

### Глобальный слой интерфейса (`.ui-layer-global`)
Содержит плавающие элементы, отображаемые поверх всех сцен:
- Кнопка «Закончить» (`#simFinishButton`) — завершение сессии и показ отчета.
- Кнопка «Датчики» (`#testSensorsButton`) — отладочная кнопка для мгновенной установки максимальных показаний приборов.
- Отладочная консоль (`#debugConsole`) — выводит дамп переменных состояния (в debug-режиме) или щиток телеметрии приборов (в prod-режиме).
- Модальное окно синхронизации экрана (`#fullscreenModal`) — блокирует симулятор, требуя перехода в полноэкранный режим.

### Раздел Ангара (`#scene-hangar`)
Разделен на три переключаемых вида:
1. **Вид сверху (`#tank-top-view`)**:
   - Фоновая картинка ангара и слой танка (`.tank-layer-top`).
   - Контейнер частиц дыма выхлопной трубы (`#exhaust-smoke-container`).
   - SVG-полигоны для люков водителя, командира, наводчика и ящика ЗИП.
   - Кнопка включения рентгена (`#xrayBtn`).
2. **Вид сбоку слева (`#tank-side-view`)**:
   - Фон левого борта танка и хитбокс перехода к обслуживанию обогревателя.
3. **Вид сбоку справа (`#tank-side-right-view`)**:
   - Демонстрационный фон правого борта.

### Раздел Обогревателя (`#scene-heater`)
Отображает котел подогревателя:
- Внутри расположен основной контейнер `.scene-content` с фоновым изображением.
- Слой хитбоксов закрытого борта (`.heater-hitbox-closed`): содержит полигоны трех шпингалетов (`hinge-latch-1..3`) и области открытия борта.
- Слой хитбоксов открытого борта (`.heater-hitbox-opened`): содержит полигоны приближения к выхлопу, закрытия борта, откручивания болтов, крышки выхлопа и установки защитного козырька.
- Кнопка возврата в ангар (`#heaterBackBtn`).

### Раздел Ящика ЗИП (`#scene-zip-box`)
Отображает разложенные инструменты:
- Фоновая текстура ящика.
- SVG-хитбокс гаечного ключа (`zip-key`) и защитного козырька выхлопа (`zip-exhaust-cap`).
- Кнопка возврата в ангар (`#zipBackBtn`).

### Раздел Кабины водителя (`#scene-driver`)
Самый насыщенный раздел:
- Фоны: темный (`.cabin-bg-dark`) и светлый (`.cabin-bg-light`).
- Слой оверлеев элементов управления (`.overlay-layer`), в который JS динамически вставляет `<img>` оверлеев переключателей.
- SVG-слой хитбоксов кабины (`.cabin-hitbox-layer`).
- Диалоговые окна выбора положений (БЦН, КПП, жалюзи, ручной газ).
- **Приборная панель КИП (`#instrumentPanelModal`)**:
  - Содержит фоновую картинку приборного щитка.
  - SVG-слой хитбоксов приборов и тумблеров (`.instrument-panel-hitbox-layer`).
  - Слой оверлеев стрелок и тумблеров.

## Архитектурные предупреждения (Структурные баги)

> [!WARNING]
> **Дублирование ID и разметки сцены командира**
> В текущей версии `index.html` присутствуют две секции с одинаковым идентификатором `id="scene-commander"`:
> - Первая секция (строки 538–704) содержит разметку кабины командира с правильным аспектом SVG (`preserveAspectRatio="xMidYMid meet"`), но также содержит **полные копии** модальных окон БЦН, жалюзи, КПП и приборной панели, скопированные из кабины водителя.
> - Вторая секция (строки 705–733) содержит чистую разметку кабины командира без дублированных модалок, но с растянутым аспектом SVG (`preserveAspectRatio="none"`).
> 
> *Рекомендация по исправлению:* Удалить дублирующиеся модалки из первой секции сцены командира, а вторую секцию полностью вырезать из HTML-файла. Это устранит дублирование DOM-идентификаторов (`bcnModal`, `instrumentPanelModal` и др.), из-за которого методы `document.getElementById` могут находить неверные элементы.
