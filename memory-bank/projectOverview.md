# Обзор проекта: Симулятор кабины танка Т-72

## Краткое описание

Веб-симулятор кабины механика-водителя танка Т-72. Пользователь взаимодействует с элементами управления (переключатели, рычаги, педали) на 2D-изображении кабины, выполняя процедуру запуска двигателя в правильной последовательности.

## Цель проекта

Обучающий тренажёр для отработки последовательности действий при запуске двигателя танка Т-72 в различных условиях (метод пуска, температура окружающей среды).

## Основные сценарии использования

1. **Тренировка** — пользователь выбирает условия (способ запуска, температура, тип топлива) и выполняет чеклист действий.
2. **Инструкция** — просмотр справочных материалов (в разработке).

## Текущий функционал

- **Ангар** — начальная сцена с танком. Поддерживает три режима просмотра:
  - *Вид сверху (Top View)* — вход в кабину водителя, командира или наводчика через соответствующие люки, а также доступ к ящику ЗИП. Поддерживает режим "Рентген" (отображение внутренних узлов).
  - *Вид сбоку слева (Side View)* — переход к обслуживанию обогревателя.
  - *Вид сбоку справа (Side Right View)* — демонстрационный вид правого борта.
- **Кабина водителя** — основная интерактивная сцена с органами управления и приборами. Включает динамическое освещение (вкл/выкл по кнопке плафона при включённой массе).
- **Кабина командира** — сцена башни с возможностью наклона обзора (переключение straight/tilted) и доступом к клапану подачи топлива на обогреватель.
- **Обогреватель (Heater Subsystem)** — сцена обслуживания котла подогревателя. Включает открытие шпингалетов, открытие борта, откручивание болтов крышки выхлопа с помощью ключа из ЗИП, снятие крышки и установку защитного козырька.
- **Ящик ЗИП (ZIP Box)** — сцена инвентаря для взятия гаечного ключа и защитного козырька выхлопа.
- **Приборная панель** — детальный вид панели КИП с интерактивными тумблерами, кнопками, АЗР и динамическими стрелочными приборами.
- **Звуковая система (AudioManager)** — воспроизведение звуков тумблеров, кнопок, стравливания воздуха, подкачки топлива БЦН, а также динамический синтез звуков стартера и двигателя (громкость и тональность зависят от оборотов двигателя и положения педали газа / ручной подачи).
- **Система дыма (ExhaustSmoke)** — визуализация выхлопных газов на виде сверху в ангаре. Интенсивность, частота появления и цвет частиц зависят от оборотов двигателя.
- **Система тренировки** — отслеживание выполнения шагов чеклиста с механизмом взведения (arming) для строгого соблюдения последовательности.
- **Телеметрия** — отображение точных численных показателей датчиков в реальном времени.

## Режимы работы

| Режим   | Описание                                                                              |
| ------- | ------------------------------------------------------------------------------------- |
| `debug` | Видны SVG-хитбоксы (красная заливка), отладочная консоль с состоянием всех параметров |
| `prod`  | Хитбоксы невидимы, консоль показывает телеметрию приборов на русском языке            |

Переключение режима: константа `APP_MODE` в `main.js` (`"debug"` или `"prod"`).

## Ключевые особенности реализации

1. **Чистый Vanilla JS** — без фреймворков и внешних библиотек.
2. **SVG-хитбоксы** — невидимые полигоны поверх 2D-изображения для точных кликабельных зон.
3. **Data-driven UI** — элементы обновляются через подписку на изменения состояния.
4. **Физическая симуляция** — давление воздуха и топлива, температура, обороты, напряжение и сила тока изменяются плавно через `tick(dt)`.

## Текущие сценарии тренировки

1. **Подготовка к пуску: +20°C, дизель** — 11 шагов, включающие осмотр, открытие баллонов, включение массы, прокачку топлива БЦН и подачу предупредительного сигнала.
2. **Подготовка и пуск сжатым воздухом: +20°C, дизель** — 20 шагов, включающие полную подготовку, закачку масла насосом МЗН-2, прокрутку коленвала сжатым воздухом через ЭПК-48 без топлива, последующий пуск с подачей топлива (нажатием педали газа) и установку минимальных оборотов холостого хода.
