# Обзор проекта: Симулятор кабины танка Т-72

## Краткое описание

Веб-симулятор кабины механика-водителя танка Т-72. Пользователь взаимодействует с элементами управления (переключатели, рычаги, педали) на 2D-изображении кабины, выполняя процедуру запуска двигателя в правильной последовательности.

## Цель проекта

Обучающий тренажёр для отработки последовательности действий при запуске двигателя танка Т-72 в различных условиях (метод пуска, температура окружающей среды).

## Основные сценарии использования

1. **Тренировка** — пользователь выбирает условия (способ запуска, температура) и выполняет чеклист действий
2. **Инструкция** — просмотр справочных материалов (в разработке)

## Текущий функционал

- **Ангар** — начальная сцена с танком, вход в кабину через люк
- **Кабина водителя** — основная сцена с интерактивными элементами управления
- **Кабина командира** — дополнительная сцена (базовая реализация)
- **Приборная панель** — модальное окно с детальными переключателями
- **Система тренировки** — отслеживание выполнения шагов чеклиста
- **Телеметрия** — отображение показаний датчиков в реальном времени

## Режимы работы

| Режим   | Описание                                                                              |
| ------- | ------------------------------------------------------------------------------------- |
| `debug` | Видны SVG-хитбоксы (красная заливка), отладочная консоль с состоянием всех параметров |
| `prod`  | Хитбоксы невидимы, консоль показывает телеметрию приборов на русском языке            |

Переключение режима: константа `APP_MODE` в `main.js` (`"debug"` или `"prod"`).

## Ключевые особенности реализации

1. **Чистый Vanilla JS** — без фреймворков и внешних библиотек
2. **SVG-хитбоксы** — невидимые полигоны поверх 2D-изображения для точных кликабельных зон
3. **Data-driven UI** — элементы обновляются через подписку на изменения состояния
4. **Физическая симуляция** — давление, температура, обороты изменяются плавно через `tick(dt)`

## Текущий сценарий тренировки

**Стартер-генератор при +15°C** — 16 шагов от установки нейтрали до контроля напряжения после запуска.
