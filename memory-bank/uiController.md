# UIController — Управление пользовательским интерфейсом

**Файл:** `js/UIController.js`

## Назначение

Связывает DOM-структуру симулятора с центральным состоянием `TankState`:
- Отслеживает действия пользователя (клик, нажатие, удержание, тач-жесты, перетаскивание слайдеров, наведение мыши).
- Отображает поверх фоновых изображений кабины соответствующие спрайты переключателей в зависимости от их текущего состояния.
- Рендерит положение стрелок КИП на приборной панели.
- Отображает всплывающие подсказки с точными цифровыми значениями приборов.
- Управляет выводом логов в отладочную или бортовую консоль.

## Свойства класса

- `_overlayLayerEl` — контейнер слоя наложения визуальных спрайтов элементов управления.
- `_controlOverlayEls` — карта ассоциаций (`Map`), связывающая идентификатор действия (`action`) с HTML-элементом `<img>` оверлея.
- `_controlOverlayMeta` — метаданные геометрического положения хитбокса во viewBox (для корректного пропорционального масштабирования оверлея).
- `_gaugeArrowEls` — карта ассоциаций (`Map`) стрелок приборов КИП.
- `_manometerTooltipEl` / `_gaugeTooltipEl` — DOM-элементы всплывающих подсказок для манометра и приборов соответственно.
- `_hitboxVisible` — флаг отображения границ и названий зон хитбоксов (в режиме `debug`).
- `_touchHeldAction` — идентификатор педали, удерживаемой в данный момент на тач-устройстве.

## Обработка взаимодействия

### Клики по элементам (Toggle / Cycle)
При клике на хитбокс или изображение оверлея запускается обработчик, вызывающий соответствующий метод в `TankState`:
- Простые переключатели (масса, баллоны, клапаны, АЗР, тумблеры КИП): вызывают `toggle` или `cycle` методы состояния.
- Открытие приборной панели: переключает флаг в состоянии, отображая модальное окно КИП.

### Удержание (Педали остановочного тормоза и газа)
Педали работают только при удержании:
- События `mousedown` и `touchstart` на педали вызывают `state.setBrakePressed(true)` или `state.setGasPedal(true)`.
- События `mouseup`, `touchend`, `mouseleave` сбрасывают состояние педалей в `false`.

### Модальные окна управления с выбором состояния
Для ряда сложных органов управления вместо простых кликов открываются специализированные модальные окна выбора положения:
1. **БЦН ТЦА (`_showBcnModal`)** — содержит выбор из 3 режимов: "Выключено", "Включено", "Откачка". Обновляет кнопку и картинку крана.
2. **Рычаг жалюзи (`_showShuttersModal`)** — содержит выбор положений 0..4 (от "Закрыто" до "Открыто"). Рендерит положение рукоятки на шкале жалюзи.
3. **Коробка передач (`_showGearModal`)** — выбор передач от нейтрали, передач 1–7 до заднего хода (3Х). Рендерит положение рычага в кулисе.
4. **Ручная подача топлива (`_showFuelFeedModal`)** — содержит интерактивный вертикальный слайдер (0–100%). Пользователь может перемещать ползунок (`pointerdown`, `pointermove`, `pointerup`), задавая точный процент подачи топлива.

Все открытые модальные окна закрываются автоматически при клике вне их контента (реализовано через глобальный перехватчик `pointerdown` на уровне документа).

### Подсказки приборов при наведении (Tooltips)
Чтобы пользователь мог точно считывать показания приборов (так как текстуры шкал растровые и мелкие), реализована система всплывающих подсказок:
- **Манометр**: при наведении на хитбокс манометра рассчитывается среднее давление из открытых воздушных баллонов и выводится подсказка в формате `Х.Х кгс/см²`.
- **Приборы приборной панели**: при наведении на любой круглый прибор рассчитывается его значение на основе сенсоров состояния (с учетом положения переключателей баков или тумблера амперметра) и выводится подсказка с текущим значением и единицей измерения.
Подсказки плавно следуют за курсором мыши (`mousemove`).

## Рендеринг стрелочных приборов

Стрелки приборов не используют покадровые спрайты. Вместо этого применяется поворот одной картинки стрелки:
1. В `ControlOverlayDefs.js` для каждого прибора заданы:
   - Координаты центра вращения во viewBox (`cx`, `cy`).
   - Размеры стрелки (`arrowW`, `arrowH`).
   - Точка привязки оси вращения на изображении стрелки в процентах (`pivotX`, `pivotY`, например `58% 70%`).
   - Углы, соответствующие минимальному и максимальному значению (`startAngle`, `endAngle`).
2. В `UIController._updateGaugeArrows(snapshot)` текущее физическое значение нормализуется (от 0 до 1). Для асимметричной шкалы прибора ВА-540 левая и правая половины шкалы нормализуются раздельно относительно точки нуля `zeroOffset`.
3. Угол вычисляется по формуле: `angle = startAngle + normalized * (endAngle - startAngle)`.
4. В DOM-элемент стрелки записываются CSS-переменные поворота, которые применяются в файле стилей:
```css
.overlay.gauge-arrow {
  transform-origin: var(--pivot-x) var(--pivot-y);
  transform: rotate(calc(var(--rot, 0) * 1deg));
}
```

## Синхронизация освещения и видов

В методе `_render(snapshot)` контроллер синхронизирует дополнительные состояния сцен:
- **Кабина командира**: если в состоянии `commanderView === "tilted"`, к контейнеру сцены командира добавляется CSS-класс `.commander-view-tilted` (активирующий наклон фона и 3D-перспективу).
- **Свет в кабине водителя**: если включена масса и тумблер плафона `cabinLight`, к кабине водителя добавляется класс `.cabin-lights-on`, переключающий фоновое изображение на светлую версию.
- **Отчет КИП в консоли**: в режиме `prod` консоль форматирует показания всех 13 ключевых параметров приборов в читаемую таблицу на русском языке.
